# Чат для репетиции

## Сайт

Из папки проекта выполните `python build_site.py`, затем
`python -m http.server 8000 --bind 127.0.0.1 --directory dist`.
Откройте http://127.0.0.1:8000. На сайте есть чат, пять кнопок тем,
быстрые вопросы и сброс переписки. После изменения `faq.txt` повторите
`python build_site.py` и обновите страницу. Сайт работает без сторонних
библиотек; переписка хранится только в открытой вкладке.

При разработке использованы рекомендации `frontend-project-fit`,
`frontend-copy-guard` и `frontend-runtime-qa` из
[frontend-workbench](https://github.com/akenoowww/frontend-workbench/tree/main/skills).

## Терминальный бот

Небольшой терминальный бот отвечает на пять вопросов: время репетиции,
состав команды, учебный трек, сдача работы и призы. Вопросы, ответы и
ключевые слова хранятся в `faq.txt`. **Все условия демонстрационные:**
перед сдачей замените время, размер команды и другие условия на реальные.

## Как запустить

Нужен Python 3.8 или новее; дополнительные библиотеки не требуются.
Откройте терминал в папке проекта и выполните:

```sh
python main.py
```

В Windows также можно использовать `py main.py`, в Linux/macOS —
`python3 main.py`. Вводите вопросы по одному. Команда `выход` (также
`exit` или `quit`), Ctrl+C или конец ввода завершают чат.

## Что получилось

Бот приводит текст к нижнему регистру, заменяет «ё» на «е» и разбивает
вопрос на слова. Для каждой записи считает число разных слов,
совпавших с её ключами, и выбирает ответ с максимальным баллом.
Звёздочка в конце ключа обозначает начало слова: `команд*` подходит
для «команда» и «команде». При отсутствии совпадений или равенстве
лучших баллов бот отвечает «не знаю». RAG, модели и интернет не нужны.

Примеры: «Во сколько начало?» → время; «Какой состав команды?» →
размер команды; «Какой трек?» → учебное задание; «Куда отправить работу?»
→ порядок сдачи; «Будут призы?» → информация о призах;
«Какая погода?» → «не знаю».

Поиск простой: незнакомые синонимы и опечатки могут не распознаваться,
а ключевое слово в постороннем вопросе может вызвать ответ из FAQ.
Для изменения поведения отредактируйте строки `Ключи` в `faq.txt`.
Для сдачи перенесите файлы в репозиторий команды и передайте ссылку.
